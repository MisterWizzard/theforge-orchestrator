=== BLK-017 fix, verified (02:18) =======================================================

scripts/runtime/register-runtime.ps1 now adds a watchdog trigger per task: a Once trigger
with a repetition interval and no duration, which repeats for the life of the task on
Windows 10 and later, alongside the logon trigger. MultipleInstances IgnoreNew makes each
repeat a no-op while the process lives; the first repeat after a death starts it again. It
does not use the restart-on-failure machinery that failed above. -WatchdogMinutes tunes the
interval (default 1); -NoWatchdog restores the old behaviour.

  02:18:43  port 4400 = 1, task State = Running   <- REVIVED, 22 seconds
The task's scheduled NextRunTime was 02:18:35, so the watchdog fired exactly on schedule.
Both tasks now report Triggers.Count = 2.

Side effect handled: while healthy, the ignored repeat makes Task Scheduler record
0x800710E0 / 0x8004131F as the task's last result every minute. `pnpm forge runtime status`
now names both as "watchdog repeat refused/ignored, the task is already running (healthy)"
so an operator does not chase a phantom failure; 0xFFFFFFFF is deliberately left as
unknown, so a genuinely killed process still reads as a fault.
